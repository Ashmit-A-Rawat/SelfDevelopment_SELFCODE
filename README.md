# SelfCode Academy - Web Development Demo

## Overview

SelfCode Academy is a responsive front-end web development project created as part of a technical assessment. The project demonstrates core web development concepts using HTML, CSS and JavaScript while following modern responsive design principles.

The website showcases a fictional coding academy and includes multiple sections such as a hero banner, responsive navigation, CSS Grid and Flexbox demonstrations, course cards and a contact form.

---

## Features

### Responsive Navigation

* Sticky navigation bar
* Mobile-friendly hamburger menu
* Smooth scrolling between sections
* Active section highlighting

### Modern UI Design

* Clean and responsive layout
* Custom color palette using CSS variables
* Interactive buttons and hover effects
* Professional typography using Google Fonts

### CSS Layout Demonstrations

* Flexbox implementation
* CSS Grid implementation
* Responsive breakpoints for mobile devices

### Interactive Components

* Mobile menu toggle
* Smooth scrolling navigation
* Contact form validation
* Dynamic active navigation states
* Hover animations for cards and layout elements
